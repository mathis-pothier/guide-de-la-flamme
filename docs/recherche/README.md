## Conventions

- **[1.0]** : l'info vient d'une source postérieure au 15/10/2026 ou des fichiers 1.0 (notes officielles, PinDrop, enshrouded.tools).
- **[pré-1.0]** : l'info vient d'une source antérieure (accès anticipé, update 7 « Wake of the Waters » ou avant). À revérifier.
- **⚠ Divergence** : deux sources se contredisent ; les deux versions sont notées.
- Les noms propres du jeu sont laissés en **anglais** (Shroud Root, Elixir Well…) : la traduction française officielle en jeu
  n'a pas pu être vérifiée (les guides FR utilisent « brume », « racine », « puits d'élixir », « autel de la Flamme »).
  À relever en jeu avant de rédiger les pages, pour coller au vocabulaire que voient les joueurs.
- Les références `[id]` renvoient à [09-sources.md](09-sources.md).

## Droits

Les faits de jeu (chiffres, recettes, noms) ne sont pas protégés, mais les textes, cartes et captures des sites tiers le sont.
Tout ici est **reformulé**. Aucune carte, tuile, liste de marqueurs ou capture n'a été reprise d'AllThings.How, th.gl ou
Map Genie ; ils sont seulement cités comme sources de faits. Le wiki (enshrouded.wiki.gg, CC BY-SA) n'a pas pu être consulté
depuis l'environnement cloud (bloqué) : ses données restent récupérées par la collecte automatique du site.
